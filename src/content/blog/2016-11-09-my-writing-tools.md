> 我日常非工作时间外的学习，基本流程就是收藏、写作和分享，所以把这三段写在一篇文章里。记录这个过程的意义在于：清楚地知道自己在做哪件事的时候，该用哪个工具。工具年年换，但「每个环节只有一个入口」的原则一直没变。

## 收藏：只收藏会读的东西

这部分准确地说应该是收藏和阅读，因为**只收藏不阅读是没有任何意义的**——收藏夹不是坟墓，是缓沖区。

### 网站收藏：Safari 收藏夹 + Alfred

网站的收藏我只用 Safari 自带的收藏夹，因为它完全满足我的三个要求：

1. **添加方便**：一键加入；
2. **全设备同步**：iPhone、iPad、Mac 无缝；
3. **检索方便**：用 Alfred 直接打开。

我主力浏览器是 Safari。大屏下侧边栏可以很方便地打开常用网站，再配合 Alfred 的书签搜索，从「想打开某个网站」到「网站打开」不超过两秒。收藏网站这件事，浏览器原生能力足够了，不需要专门工具。

### 文章收藏：全部收口到 Instapaper

文章、微博这类内容级收藏，统一用 Instapaper。这个软件被 Pinterest 收购后 Pro 功能全部免费，堪称良心。Pro 的必备功能包括**全文搜索、文章片段高亮、笔记**，都能明显提升阅读和笔记体验。

我的阅读来源主要是 Reeder（RSS），然后是微信公众号、知乎、微博和即刻。来源太广的问题在于：**用各平台自带的收藏，过一阵子就忘了东西存在哪**。所以策略是无论从哪看到的，一律先丢进 Instapaper，「稍后读的东西在哪」永远只有一个答案。

## 写作：按「写给谁」分三类

写作需求不是铁板一块，按用途分三类后，每类的工具选型标准就清晰了。

### 博客写作：MWeb

写公开博客时，我对工具只有四个要求：

1. 支持原生 Markdown（不锁格式，随时可迁移）；
2. 支持显示文章 TOC（长文写作必须有导航）；
3. 支持文件管理（几百篇文章要有秩序）；
4. 可以灵活导出到其他格式。

尝试过 Ulysses、Quiver、Day One 之后，最终选择了 **MWeb**。它的使用体验最贴合需求：左侧直接导入存放博文的 GitHub 本地目录，可以直接添加文件和书写，创建文件时还自动以当前日期命名——现在我博客的文章组织方式与此如出一辙，这也是我最喜欢的管理和阅读布局。右边栏是当前文章的目录，可以在不同子标题间方便地跳转，写长文时非常踏实。

导出部分 MWeb 也做得面面俱到，常用的格式都包含。值得一提的是它对 Evernote 的导出支持非常好，格式、速度、管理都在线。

### 知识总结：Evernote

对于总结性的笔记，**整理和检索的需求比书写方便更重要**——总结的目的本来就是为了以后用到的时候能立刻找到。从这方面来说，至今没有发现一个软件比得上 Evernote。

它的检索做到了顶尖水平：全文搜索瞬间完成，连 **PDF 和图片里的文字都能搜到**。配合标签体系，可以把一个主题的多篇笔记串起来，需要时按标签一拉全出来。

Evernote 的使用我克制在三个功能内：检索、剪辑归档、多平台同步。对于它推崇的剪藏及快速笔记功能我一概不用，因为我得确保自己知识库里面的东西，**都是认真整理过的**——入库即终稿，这个纪律比任何工具都重要。

### 片段笔记：Unclutter 与 Day One

有时候需要的只是片段记录：别人发来一个地址，或者脑海里突然闪过一个念头。

- **Mac 上**：Unclutter 足够好用。鼠标移到顶栏往下一滑，笔记就在那里，记完即走，没有打开 App 的心理负担；
- **手机上 / 稍重要的事 / 日记**：Day One。它自动给每条记录标记好上下文——日期、GPS、当天天气，事后翻起来细节都在。Mac 顶栏也有快捷入口。

## 分享：发布成本越低越好

### 博客发布

博客用 GitHub + Jekyll 生成，发布没有多余步骤：写好文章，命令行 push 一下。本来这个过程也可以用工具简化，但我有意保留手动提交——**发布前的检查过程本身就是一道质量闸**，顺手确认一遍改动再上线，比一键发布安心。

### 社交分享

Mac 下各软件的分享功能已经做得很简单。系统侧边栏的快速分享组件可以把内容发到各个社交网站；涉及图片分享时，用 Dropzone 的扩展直接把图片拖到相应图标上即可完成上传。

## 写在后面

这套工具链的核心逻辑到今天依然成立：**收藏统一入口（防散）、写作分场景（防混）、发布留一道检查（防错）**。具体软件倒是换了好几轮——MWeb 之后的写作工具市场被 Obsidian、Typora 们重新洗牌，Evernote 也早已不是唯一选择。但每次换工具，标准都没变过：数据格式开放、检索够快、单一路径。工具是流程的载体，流程稳定了，换什么工具都只是换个壳。
