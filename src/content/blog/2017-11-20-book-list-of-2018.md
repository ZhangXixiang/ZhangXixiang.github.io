> 2018 始。度过了有那么一段时间的晃荡，人渐渐能沉下心，读一些书。这份书单分两半：一半是生活层面的减法（《极简生活》），一半是技术层面的纵深——Java 进阶的七本书，从语言到虚拟机到框架源码，一条线打穿。

## 极简生活

我们的生活真的需要那么多的东西吗？整理房间会重生，整理一下自己呢？

这本书对我最大的触动是把「拥有」和「需要」拆开了看：物品的价值在「被使用」的那一刻就已经兑现，囤着不用反而是负资产。整理房间只是表象，**整理的是自己和物品的关系**——这个视角迁移到信息消费上同样成立（收藏夹、订阅源、App，哪个不是越攒越多）。

## Java 进阶七本书

技术阅读的主线是往深水区走：

- 《Thinking in Java》：思维方式的地基，常读常新；
- 《Spring 实战》《Spring Boot 实战》：框架的用与快速上手，两本搭配着读，一个讲体系一个讲效率；
- 《JDK8 实战》：Lambda 与 Stream，Java 函数式的转折点；
- 《深入理解 Java 虚拟机》：JVM 三件套——内存模型、垃圾回收、类加载，Java 进阶绕不开的一本；
- 《Spring 源码解析》：从「会用」到「知道为什么」，IOC 和 AOP 在源码层面长什么样；
- 《Effective Java》：最佳实践的清单，每条都值得想想「为什么」。

这七本不是并列关系，而是**层次关系**：语言（Thinking in Java / JDK8 / Effective Java）→ 虚拟机（深入理解 JVM）→ 框架（Spring 双雄 + 源码解析）。读完一层再上一层，比按畅销榜乱读有效得多。

## 写在后面

多积累，把这个世界交给别人，我真的不放心啊。

这句当年写在书单末尾的话，是整份清单里我最喜欢的一句——读书的原动力，说到底就是这份「不放心」。
