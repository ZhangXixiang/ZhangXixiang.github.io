> 2013 年是我技术视野快速打开的一年：从纯 Web 开发往 NoSQL、安全两个方向各探了一步，也第一次认真读了科技商业史。这份书单记录了四本书，每本都对应一个具体的问题。

## Pro Git

[在线阅读](http://git-scm.com/book)

Git 的权威读本，由 GitHub 的 Scott Chacon 执笔，完整覆盖从日常操作到内部原理。当年读它最大的收获是把 `rebase`、分支模型这些「知其然」的操作彻底搞成了「知其所以然」。这本书开源免费，至今仍在更新，依然是 Git 入门的第一推荐。

## The Little MongoDB Book

[在线阅读](https://github.com/karlseguin/the-little-mongodb-book/blob/master/en/mongodb.markdown)

Karl Seguin 的「Little Book」系列之一，几十页就把 MongoDB 讲完了。这本书非常简洁，读起来非常易懂——其实这也归功于 MongoDB 本身的简洁。

NoSQL 与 MySQL 最大的区别在于它是为一些特定场景设计的：MongoDB、Redis、Cassandra 各有所长，而 MongoDB 是其中更通用的方案。从 MySQL 转 MongoDB，心智模型的变化比语法变化大：没有 Join、Schema 自由、以文档为中心。从 MySQL 往 MongoDB 转，几乎不需要太大变化——这是当年读完的实际感受，也是后来我在真实项目里验证过的。

## 白帽子讲 Web 安全

[豆瓣链接](http://book.douban.com/subject/10546925/)

吴翰清（刺）的代表作，国内 Web 安全领域的经典入门书。XSS、CSRF、SQL 注入、点击劫持……这本书第一次让我意识到：**平时写的每一个表单、每一条拼出来的 SQL，都可能是一道敞开的门**。对开发者的价值不在于教你成为安全工程师，而在于写代码时脑子里多一根弦。

## 浪潮之巅

[豆瓣链接](http://book.douban.com/subject/6709783/)

吴军的科技商业史名作，讲的是 AT&T、IBM、苹果、微软、谷歌等公司如何站上浪潮之巅又如何被下一波浪潮掀翻。技术人读它的意义在于建立「行业周期」的视角：**一家公司的命运，很大程度上取决于它站在浪潮的哪个位置**。这本书对我在后来几年判断技术方向的选择，影响比想象中大。

## 写在后面

一年四本书，量不算大，但每本都有明确的动机：学工具（Pro Git）、学新存储（MongoDB）、补安全意识（白帽子）、开行业视野（浪潮之巅）。现在回头看，带着问题读书、读完能用，比囤书单重要得多。
