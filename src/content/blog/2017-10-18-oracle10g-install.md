> Oracle 10g（10.2.0）发布于 2005 年，官方认证的操作系统只到 Windows XP / Server 2003。要在 Win10 上把它装起来，核心技巧就一个：**兼容性安装**。这篇是当年的实操记录，十步走完，数据库、监听、iSQL*Plus 全部就绪。

## 前置说明：为什么 Win10 装不上「正常装」

Oracle 安装程序在启动时会校验操作系统版本，10g 的安装器不认识 Win10，直接运行通常在「检查操作系统版本」一步就被拦下。通用的处理思路有两类：

1. **兼容性模式运行**（我用的是这种，亲测可用）：右键 `setup.exe` → 属性 → 兼容性 → 以 Windows XP SP3 模式 + 管理员身份运行；
2. 修改安装介质里的 `oraparam.ini` 与 `refhost.xml`，把 Win10 的版本号（6.x）加进认证列表——属于通用的破解式做法，效果等同。

## 安装十步记录

以下按当时的实际流程记录：

1. **兼容性安装**：以 XP SP3 兼容模式 + 管理员身份启动 `setup.exe`，安装器正常进入图形界面；
2. **安装检测（硬件、软件）**：检查物理内存、虚拟内存、磁盘空间是否达标；
3. **产品特定的先决条件检查**：网络配置、路径注册表等检查项——**部分显示未成功也不影响安装**，勾选「继续」即可；
4. **安装前的概要提示**：罗列即将安装的组件、Oracle 主目录路径、全局数据库名等信息，确认后进入正式安装；
5. **进行安装**：复制 Oracle Database 10g 10.2.0.1.0 的文件，这一步耗时最长；
6. **Configuration Assistant 配置启动组件**：依次配置 Net Configuration Assistant（监听器）、iSQL*Plus 等；
7. **Database Configuration Assistant**：创建数据库实例，完成后会解锁 system 等账户的设置界面；
8. **安装成功**：摘要页会给出 iSQL*Plus 的 DBA 入口地址 `http://<主机名>:5560/isqlplus/dba`；
9. **登录控制台查看 Oracle 详细信息**：用浏览器打开 iSQL*Plus 或本地 sqlplus 验证实例状态；
10. **连接验证**：用 DBVisualizer 连接数据库（默认账户的密码自装库时设置），确认可以正常建库建表。

## 几个当年值得记的点

- **先决条件检查不必全绿**：兼容模式绕过版本校验后，个别网络相关检查项会失败，实测不影响数据库本身运行；
- **版本号是 10.2.0.1.0**：这是 10g Release 2 的基础版，装完如需升级到 10.2.0.4/10.2.0.5 还要打补丁包；
- **iSQL*Plus 是 10g 特有的网页版 SQL 工具**，11g 之后就被废弃了——当年用浏览器写 SQL 还挺新鲜。

## 写在后面

如今再看，10g 连 Win10 都要靠兼容模式「骗」过安装器，属于典型的**老软件新系统**兼容问题。这类问题的通用解法也值得记一笔：要么让程序以为自己在老环境（兼容模式），要么改程序自己的认证清单（改配置文件）。后来装各种老中间件、老客户端时，套路完全一样。当然，现在学 Oracle 直接上 19c/23ai 的 Docker 镜像几分钟就能起一个，再也不用受这份罪了。
