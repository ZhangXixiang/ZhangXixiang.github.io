> 2017 年的关键词是「换赛道」：新进了一家互联网公司，接手的代码是 PHP 写的，于是读书清单被工作推着走——PHP 补习、Git 深入、Python 起步。读书第一次和饭碗绑得这么紧。

## 好好使用 Kindle

新进了家互联网公司，需要做代码迁移，原来的代码使用 PHP 写的，所以要补习这门语言——《零基础学 PHP+MySQL》。

PHP 是当时比较流行的非客户端 Web 程序开发语言之一，主要特点是语法简单、学习容易、功能强大，对初学者容易接受且容易上手。PHP、MySQL 和 Apache 的组合当时已经是 Web 服务器的一种配置标准。从 Java 背景转过来，大框架不用换脑子，真正要记的是语法细节的差异。

经过一段时间的学习，发现有些小地方还是与 Java 不同的，例如：

```java
// Java 拼接字符串
String str = "hello" + "world";
```

```php
// PHP 拼接字符串
$str = "hello" . "world";
```

笔者自以为 PHP 也是用 `+` 连接字符串，闹了个笑话，以此记录！——这类「想当然」的坑，每个学第二门语言的人都躲不掉，只能靠踩一个记一个。

## Git 权威指南

蒋鑫的这本大部头（机械工业出版社）。Git 是一款分布式版本控制系统，有别于 CVS 和 SVN 等集中式版本控制系统：Git 可以让研发团队更加高效地协同工作，开发人员的工作不会因为频繁遭遇提交冲突而中断，管理人员也无须为数据备份担心。经过 Linux 这样庞大项目的考验后，Git 被证明可以胜任任何规模的团队，即便团队成员分布于世界各地。

2014 年我整理过一份 Git 常用命令手册（见本博客《Git 日常操作手册》），但停留在「会用」层面；这本读的是底层——对象模型、引用、reflog，读完才算真正理解分支为什么廉价、reset 和 checkout 到底动了什么。

## 编程小白的第一本 Python 入门书

其次，Python 功能强大，很多你本来应该操心的事情，Python 都替你考虑到了：不需要考虑内存管理之类的底层细节。并且 Python 有很丰富的库——官方的、第三方的都有——你想做的功能模块很有可能已经有人写好了，只需要调用，不需要重新发明轮子。这就像是拥有了智能手机，可以任意安装需要的 app。

当年学 Python 还带着「备一门脚本语言」的心态，谁也没料到几年后它会借着 AI 的东风变成最热门的语言。

## 写在后面

这一年的书单几乎全由工作驱动：要迁移 PHP 代码就补 PHP，要管好仓库就啃 Git，要看懂脚本就学 Python。「用什么学什么」在学生时代看起来像功利，工作后才发现这是效率最高的路径——**带着真实问题读书，每一页都有反馈**。
