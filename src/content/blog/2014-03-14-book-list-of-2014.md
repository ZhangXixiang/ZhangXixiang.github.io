> 2014 年的书单不长，三本书对应三个方向：把上一年开始的 Web 安全学习继续深入，用一本小册子速成 Redis，再从 Facebook 的故事里看研发团队怎么运作。

## Web 前端黑客技术揭秘

[豆瓣链接](http://book.douban.com/subject/20451827/)

承接上一年《白帽子讲 Web 安全》的继续深入。区别在于视角：这本从**前端攻击者的角度**出发，把 XSS、CSRF 这些漏洞的利用链路拆开讲——攻击者是怎么一步步构造 payload、怎么绕过过滤、怎么把一个反射型 XSS 升级成会话劫持的。理解了攻击路径，防御措施才不是死记硬背的清单，而是针对性的拆招。

## The Little Redis Book

[在线阅读](https://github.com/karlseguin/the-little-redis-book)

Karl Seguin 的 Little Book 系列再次上榜——上年读了同系列的 MongoDB 分册，这次是 Redis。同样是几十页的体量：数据结构（String/List/Hash/Set/ZSet）、过期策略、持久化（RDB/AOF）、发布订阅一气呵成。

这个系列最厉害的地方是**只讲心智模型不堆 API**：读完你会知道 Redis 为什么快（内存 + 单线程无锁）、每种数据结构适合什么场景，而不是背一堆命令。之后项目里用到 Redis 做队列和缓存，基础都是这本小册子打的。

## 打造 Facebook

[豆瓣链接](http://book.douban.com/subject/20471120/)

前 Facebook 中国员工王淮写的亲历记，讲 Facebook 的工程文化：Hack 文化、Code Review 制度、工具文化（内部工具团队的地位极高）、快速迭代而不失控的秘密。

对开发者的启发是**制度层面的**：好的工程产出不是靠招到天才，而是靠让普通工程师也能高效协作的流程和工具——Code Review 不是找茬，是知识流动；内部工具不是成本，是生产力。这些观点在后来国内的研发文化演进里被反复验证。

## 写在后面

三本书，两个技术方向加一个组织观察，延续了「带着问题读书」的路子：安全补攻击视角、Redis 为项目储备、Facebook 满足对大厂工程文化的好奇。读书清单的价值不在长度，在读完后留在手上的东西。
